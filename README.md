# Sevenine Story Studio

Генератор сторис 1080 × 1920 для Sevenine. Один файл, без сборки — открывается в браузере.

**Живая версия:** https://sevenineuz.github.io/story-studio/

## Форматы

- **Свободные места** — сетка мест, курс, расписание и цена. Пять тем, автоподсчёт
  окончания урока (90 минут), готовые дни и уровни (Kids 1–4, General English A1–B2,
  IELTS). Отдельное состояние «мест нет» с листом ожидания.
- **Фото-сторис** — фото на весь экран, фирменный градиент снизу, логотип и текст.

## Как менять

Правится `index.html`. Пуш в `main` — GitHub Pages обновляет сайт за минуту.
